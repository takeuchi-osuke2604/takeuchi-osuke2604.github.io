## 課題内容
地域のイベントを、スマホで見る人に1ページで知らせるWebページを作ります。

## 作るもの 
・架空のイベント（例：公園で開く日曜の朝市）を知らせるページを1ページ作る ・見る人は、SNSに貼られたリンクからスマホで開く近所の人とする ・HTMLとCSSだけで作る入門のお題です

## 必要な機能 
・イベント名と、内容がひと目で分かる短い説明 ・日時、場所、参加費、持ち物 ・会場の地図へのリンク（会場は実在の公園や公民館などの公共の場所でよい。Googleマップなどの地図ページにつなぐ） ・問い合わせ先（架空のメールアドレスを文字で書くだけでよい。リンクにしなくてよい） ・写真またはイラストを1枚以上（自分で撮った写真や描いた絵、または無料で使ってよいと書かれた素材を使う） ・スマホの画面幅に合わせて表示させる設定（head に meta name="viewport" の1行を入れる）

## できたと言える状態 
・ブラウザの開発者ツールで画面の幅を375pxと320pxにしたとき、どちらも横にスクロールしない ・同じ幅で、説明文と日時・場所などの文字の大きさが16px以上ある（開発者ツールの Elements で文字を選び、Computed の font-size を見る） ・地図へのリンクを押すと、会場の地図が開く ・画像に、画像が出ないときの代わりの文字（alt 属性）が付いている ・個人の名前、自宅の住所、電話番号を載せていない

## 記録する URL 
・その他 URL：公開したページのURL（GitHub Pagesなど、だれでも開ける場所に公開する） ・コード（リポジトリ）URL：ソースコードを置いたGitHubのURL ・チャット URL：AIを使った場合は、そのやりとりの共有リンク
